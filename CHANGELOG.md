# Changelog

All notable public changes to TRMachinist will be documented here.

- Open-source repository bootstrap.

- Added synthetic public NC samples.

## [0.1.0-alpha-r33] - 2026-09-11

- Verified R33 source snapshot used as the initial public code baseline.
- Triple-dexel material-removal and regional surface-meshing pipeline.
- Controller-aware G-code parsing and rotary/coordinate infrastructure.
- WPF/DirectX simulator and self-contained smoke tests.
- Internal development benchmark improved from 125.974 s to 75.662 s for the referenced test case while accepted result checks were preserved.
